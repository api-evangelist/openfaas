OpenFaaS provides an open-source serverless functions framework that enables developers to deploy functions on any cloud, Kubernetes, or on‑premises environment. It emphasizes portability, simplicity, and production‑grade features, offering a rich ecosystem of templates, a web UI, and extensive language support. The platform is used by enterprises and hobbyists alike to build scalable, event‑driven applications with minimal operational overhead.

**Areas:** Company · Serverless · Open Source · Functions · Kubernetes

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for OpenFaaS: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
